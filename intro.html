The Curriculum

Talk Agenda

A comprehensive deep-dive into the modern generative AI stack, broken down into 9 pivotal topics.

01

Introduction to LLMs

Demystifying Large Language Models. Understand the core architecture, transformers, tokenization, and how these models predict the next word to generate coherent text.

02

LLMs in Action

Live demonstrations of multimodal generation. Exploring prompt engineering techniques for high-quality text synthesis and integrating image generation models.

03

The Evolving AI Landscape

Career trajectories in the AI era. Analyzing the shifting boundaries and responsibilities between Data Scientists, ML Engineers, and the emerging role of AI Engineers.

04

RAG & Tool Calling

Giving LLMs memory and hands. Learn how Retrieval-Augmented Generation grounds models in facts, and how Tool Calling allows them to interact with external APIs.

05

Structured Outputs

Moving from raw text to predictable data. Techniques for forcing LLMs to output valid JSON, schemas, and strictly formatted data for software integration.

06

Pattern: Routing

Introduction to Agentic workflows. How to design router agents that classify incoming tasks and dynamically direct them to specialized sub-models or tools.

07

Pattern: Parallelization

Scaling reasoning and throughput. Implementing parallel processing architectures where multiple agents work simultaneously on chunked data to reduce latency.

08

Pattern: Evaluator-Optimizer

Self-correcting AI systems. Building loops where a primary agent generates a solution and an evaluator agent critiques it, iterating until quality thresholds are met.

09

Agents vs. Workflows

The grand finale. Distinguishing between deterministic LLM workflows and truly autonomous agents. When to use strict pipelines vs. goal-oriented autonomy.

Why learn Agentic Architecture?

We are shifting from prompting models to building systems. Single zero-shot prompts are hitting their limits.

  • Higher Reliability

    Evaluator-optimizer loops catch hallucinations before they reach the user.

  • Complex Task Execution

    Routing and parallelization allow handling multi-step processes that require logic and tool use.
